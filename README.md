# 农业合作社综合财务业务管理系统（农村信用社综合财务业务管理系统）

## 一、项目简介
本项目基于 Spring Boot 3 + Vue 3 + Element Plus 构建，采用三端角色化设计，包含管理员端、财务人员端、用户端，适用于农业合作社、农村信用社等业务场景的综合财务业务管理与毕设演示。

系统已覆盖以下能力：
- 管理员端：首页驾驶舱、管理员账号与权限管理、财务人员管理、用户管理、字典管理、公告管理、留言与反馈管理、报销总控、财务总览与经营分析、系统安全与审计。
- 财务人员端：工作台首页、存款业务管理、取款业务管理、余额查询、统一交易流水、报销业务处理、公告查看、留言处理、报表分析与可视化分析、AI 助手。
- 用户端：首页概览、注册登录、个人信息管理、余额查询、存款记录查询、取款记录查询、报销申请、公告查看、在线留言/咨询、我的消息中心、AI 智能问答。
- 通用能力：全局搜索、导出打印、审核流留痕、风险预警、中文界面、移动适配。

## 二、技术栈
- 后端：Spring Boot 3、Java 17、Maven、MySQL 8
- 前端：Vue 3、Vite、Element Plus、Axios、ECharts
- 数据库：MySQL，初始化脚本位于 `db/init.sql`

## 六、使用步骤
### 1. 导入数据库
1. 打开 Navicat 或 MySQL 客户端。
2. 执行 `db/init.sql`。
3. 确认已创建 `coop_finance_db` 数据库及初始化数据。

### 2. 启动后端
```bash
cd backend
mvn spring-boot:run
```
后端默认地址：`http://127.0.0.1:8080`

### 3. 启动前端
```bash
cd frontend
npm install
npm run dev
```
前端默认地址：`http://127.0.0.1:5173`

## 九、页面说明
### 管理员端
- 首页驾驶舱：指标卡片、趋势图、业务结构图、待办事项、最近公告、风险预警。

### 财务人员端

- 业务办理：存款办理、取款办理，支持余额校验、大额预警、交易留痕。
- 业务管理：统一流水、余额查询、报销业务、公告留言、报表分析、AI 助手。

### 用户端
- 首页概览：余额大卡、本月收支、最近交易、快捷入口。
- 自助服务：个人信息、余额查询、存款记录、取款记录、报销申请、公告查看、留言咨询、消息中心、AI 问答。
